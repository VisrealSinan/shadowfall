# Shadowfall v87

Integrated game update; shipped through the existing launcher and GitHub Pages.

## Changes

- Fit all 16 Graveshade race/body portraits inside their picture frames across selection, wardrobe, preparation, pause and results scenes.
- Add 96 painted ability/passive illustrations shared by level-up cards, the in-game skill bar and pause loadout. Replace the old level-up card presentation with a dark green and bronze layout.
- Add 12 complete decoration sprites with transparent gutters and extra padding for their wind animation.
- Add 12 complete shop stalls across woodland, gothic and clockwork themes, plus an updated trading scene.
- Add directional offscreen markers for bosses, minibosses and Lost Shadows.
- Remove Soul Lure and automatic salvage notifications shown in the supplied screenshots; preserve attraction, shard rewards and pickup sounds.
- Move experience progress to the bottom, below the enlarged illustrated skill dock, with safe-area spacing.
- Allow entry into an already open shop portal even if a boss subsequently spawns. Guard against nested town entry and retain the existing battlefield on return.
- Process automatic passive upgrades before opening the level-up scene. Consume only earned levels, up to eight per frame; skip card rendering, the level-up flash and the celebration hop.
- Avoid legacy enemy baking and relighting when modern sheets draw successfully. Build silhouette masks on demand; retain up to 640 recent poses within a 16-megapixel budget and discard linked legacy frame references on eviction. Improve scenery frame reuse and skip default 100% opacity filters.
- Use Esc for PC keyboard pause; remove P from the handler and help text.

## Validation

- All game scripts parse and all 71 automated tests pass, including launcher content size and SHA-256 verification.
- Regression checks cover all skill-art mappings, Graveshade framing, XP placement, boss-marker geometry, three portal cycles, a boss appearing after portal creation, saving/continuing in town, bounded automatic upgrades, manual selection, quiet rewards, Esc/P handling and avoiding legacy sprite access.
- Real-pixel software-canvas checks validate 120 art regions and 16 Graveshade portraits. The source-region contact sheets were visually inspected; atlas row boundaries were corrected where painted rows differed from uniform slicing.
- Software-canvas enemy-renderer benchmark, same 96-frame mixed-action workloads before and after:

| Enemies / types | v86 mean / p95 | v87 mean / p95 | Canvas allocations, v86 → v87 |
| --- | --- | --- | --- |
| 120 / 8 | 0.87 / 1.16 ms | 2.02 / 2.42 ms | 465 → 161 |
| 240 / 24 | 45.38 / 54.04 ms | 4.71 / 5.95 ms | 52,364 → 577 |

The dense workload improves substantially; the smaller workload has more bookkeeping overhead. These measurements isolate enemy drawing and are not whole-game FPS estimates. A final native playtest was not run after the user stopped Computer Use with Escape. Desktop interaction stayed stopped; subsequent verification used files and automated checks.
